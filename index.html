01 / Simulation & algorithms

Autonomous Sensor & Intercept Simulation

GitHub →

An Unreal Engine C++ prototype exploring a complete sensor-to-intercept pipeline, from raycast measurements and point clouds to object tracking and trajectory prediction.

  • LIDAR-style raycast scanning with configurable sweep behavior and debug visualization.
  • Point cloud accumulation and voxel downsampling to limit point density.
  • Distance-based clustering, ground filtering, and motion-aware target association.
  • Kalman-style tracking for position, velocity estimation, and trajectory prediction.
  • Analytical intercept solving with automated tests for deterministic algorithm validation.

Scope: synthetic raycast sensing and algorithm exploration; this prototype does not model physical radar propagation.
