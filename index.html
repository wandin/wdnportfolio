Unreal Engine · Simulation · Algorithms

Autonomous Sensor & Intercept Simulation

GitHub →

A real-time Unreal Engine C++ simulation that models a sensor-to-intercept pipeline: scanning, point cloud generation, voxel filtering, clustering, object tracking, trajectory prediction, and intercept computation. The project is designed as a technical showcase for simulation-driven gameplay, robotics-inspired perception, debugging visualization, and algorithmic systems architecture.

  • LIDAR-style raycast scanning with configurable sweep behavior and debug visualization.
  • Point cloud accumulation with voxel filtering for noise reduction and data control.
  • Distance-based clustering, ground filtering, and motion-aware target association.
  • Kalman-style tracking for position, velocity estimation, and trajectory prediction.
  • Analytical intercept solving with automated tests for deterministic algorithm validation.
